# HOTFIX 01.1 — Complete PWA Offline Mode

**Goal:** Надёжный холодный запуск пяти вкладок после подтверждённой подготовки кеша.

**Architecture:** Сохранить SPA Expo Router, Service Worker и IndexedDB. Явная post-export генерация из готового `dist`, проверяемый протокол готовности кеша и повторная подготовка после сбоя сети. Пользовательские данные не входят в Cache Storage.

**Tech Stack:** Expo SDK 58, TypeScript strict, Cache Storage, IndexedDB, Jest, Playwright.

**Spec:** Запрос пользователя HOTFIX 01.1 в текущем чате; ограничения AGENTS.md и ROADMAP.md.

## Ограничения

- Только этап 01.1; без публикации, push и перехода к 02.
- Сохранить дизайн, навигацию, SVG-иконки, схему и данные IndexedDB.
- Никакого обязательного backend, внешних CDN или платных сервисов.
- Playwright WebKit не подтверждает работу физического iPhone.

## Проверяемые риски

- Потеря части кеша при существующем контроллере: готовность должна исчезнуть, онлайн — восстановиться.
- Первая регистрация не удалась: повторить при возвращении сети без перезапуска страницы.
- Недоступен или повреждён ресурс обновления: предыдущая версия остаётся рабочей.
- Вторая вкладка открыта: ручная активация ждёт её закрытия.
- Перезапуск браузера без сети: сохраняются приложение, тема и контрольная запись IndexedDB.
