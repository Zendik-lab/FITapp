# Глобальный аудит UI/UX — план исправлений

**Цель:** проверить все существующие экраны этапов 01.1 / 02 / 02.1, исправить адаптацию без перехода к этапу 03.

**Архитектура:** сохранить Expo Router, общие компоненты, тему и репозитории. На web использовать CSS env для системных областей: Expo Router 58 предоставляет нулевые safe-area контексты. На native оставить react-native-safe-area-context. Вкладка владеет верхним/боковыми отступами, нижняя навигация — нижним; полноэкранная анкета и состояния запуска — всеми краями.

**Ограничения:** не менять пользовательские данные, схему хранения и Service Worker; не публиковать, не выполнять push. Проверять работу в браузере, а физический iPhone и Expo Go перечислить отдельно.
