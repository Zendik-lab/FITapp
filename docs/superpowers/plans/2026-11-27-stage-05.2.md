# Этап 05.2

1. Расширить существующие токены движения и компоненты вместо подключения второй дизайн-системы. Ведущая карточка «Сегодня» сохраняет кольцо КБЖУ. Новые действия открываются во вложенных экранах пяти вкладок.
2. Проверить повторное копирование и Undo. Расширить документ дневника необязательными полями с проверкой в репозитории.
3. Использовать снимки продуктов и рецептов для расчётов рекомендаций, запасов и стоимости. Покупки, запасы и пользовательские цены сохранять через ту же транзакцию дневника.
4. Добавить настройки представления через существующее хранилище, затем отчёты по реальным записям и календарным датам. Весовые тенденции ждут журнала измерений.
5. Запустить проверки проекта и браузерные сценарии. Зафиксировать результаты и критерии ручной приёмки.
