# Этап 05.1 — Справочник рецептов и умный поиск

Откройте «Питание → Рецепты». Разделы «Все рецепты», «Мои рецепты» и «Избранное» доступны в прежней вкладке. «Выбрать рецепт» в дневнике открывает тот же каталог. В комплекте **150 оригинальных рецептов**, по 10 в каждой из 15 категорий, и **448 продуктов** единого локального каталога. Ингредиенты содержат массы съедобной части, а рецепты — порции, подготовку, приготовление, сложность и пошаговые инструкции.

Поиск учитывает названия, состав, категории и теги. Запросы нормализуются по регистру, пробелам и е/ё. Словарь синонимов и одна опечатка в достаточно длинном слове помогают найти рецепт, а все значимые слова запроса должны получить совпадение. Клавиша поиска и открытие найденного блюда сохраняют до восьми запросов. Готовые подсказки доступны при пустой истории. Восемь подборок, комбинируемые фильтры, индивидуальный сброс меток, и сортировки доступны офлайн.

В режиме «Что приготовить из того, что есть» выберите продукты. Вода, соль и чёрный перец исключаются из расчёта при включённой настройке. Сопоставление учитывает стабильные ID продуктов, включая их состояние, поэтому сухой рис и варёный рис различаются. Результаты группируются по числу недостающих продуктов. Процент показывает наличие ингредиентов, без учёта запасов по массе. Исключение ингредиента действует по выбранному продукту, поэтому перед приготовлением при аллергии следует сверить состав и маркировку.

Подборки по дневным целям используют записи за выбранную дату. «Подходит под оставшиеся калории» проверяет одну порцию против остатка калорий. «Поможет добрать белок» проверяет ту же границу калорий и требует как минимум 20 г белка либо весь остаток, если он меньше. Быстрый завтрак занимает до 20 минут. Высококалорийный перекус начинается с 350 ккал на порцию. Подборка для набора массы использует теги рецептов.

Готовый рецепт можно добавить в избранное, масштабировать для приготовления, отметить ингредиенты и шаги, скопировать для редактирования либо записать как одну позицию питания. Отметки приготовления живут, пока открыта карточка. Снимок КБЖУ сохраняется вместе с порцией, выбранной датой и приёмом. «Сегодня» и цели читают тот же дневник.

## Данные и лицензии

- **319 новых записей** происходят из USDA FoodData Central SR Legacy, выпуск 04/2018, CC0. Точный FDC ID сохранён для каждой строки. Калории, белки, жиры и углеводы получены из полей 1008, 1003, 1004 и 1005 на 100 г. Массы порций и штук указаны там, где найден подходящий вес в наборе. SHA-256 исходного CSV-архива — `B80817294B8850530AAEDF2E515C02593B1824F763A0FF356E5C2081643E6FD0`. [Архив USDA](https://fdc.nal.usda.gov/download-datasets/) · [Условия использования USDA](https://fdc.nal.usda.gov/api-guide/).
- **129 записей этапа 04** сохраняют прежние ID и показатели. Это справочные оценки и примеры маркировки отдельных продуктов, включая спортивное питание. Источник конкретной позиции отображается в селекторе. [Происхождение прежних данных](STAGE-04.md).
- Рецепты и инструкции подготовлены для MassTracker. КБЖУ суммируются по фактическим позициям рецепта без промежуточного округления. Значения приблизительны и меняются в зависимости от продуктов, потерь при приготовлении и бренда. Для пяти холодных смесей есть расчётный выход по массе съедобных ингредиентов. Для остальных граммы в дневнике доступны после ввода фактического выхода в собственной копии. Оценка на 100 г без выхода обозначена в карточке. Иллюстрации — локальные тематические иконки Lucide (ISC). [Лицензия Lucide](https://lucide.dev/license) · [Справочник температур](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures).
- Open Food Facts — дополнительный онлайн-источник для поиска продуктов и штрихкодов. Результаты показаны с источником, полные карточки кешируются в дневнике. [Условия Open Food Facts, ODbL](https://world.openfoodfacts.org/terms-of-use).

## Диагностика Open Food Facts

Проверка с origin действующей PWA в Chromium и WebKit получила ответы `200` для известного штрихкода и `404` для отсутствующего продукта, оба с CORS. Ранее HTTP 404 мог отображаться как временная недоступность. Текстовый поиск дал `200` в Chromium и `TypeError` в WebKit. Прямой запрос зафиксировал также `503` без `Access-Control-Allow-Origin`. Браузер в таком случае скрывает HTTP-статус, поэтому сообщение описывает сбой соединения или недоступный ответ. Для исходного случая на iPhone точная причина неизвестна.

Клиент проверяет контрольную цифру штрихкода и различает отсутствие продукта, неполную карточку, неверный запрос, запрет, лимит, сетевой сбой, таймаут и ответ сервиса с ошибкой. Текстовый поиск запускается явно с локальным ограничением частоты. Альтернативный Search-a-licious в исследованных ответах не возвращал КБЖУ. Поиск по штрихкоду и существующий текстовый API вызываются напрямую. [Документация Open Food Facts](https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/) · [Трекер CORS](https://github.com/openfoodfacts/openfoodfacts-server/issues/13475).

## Запуск и проверка PWA

```powershell
npm.cmd ci
npm.cmd run build:web
npm.cmd run verify:web
npm.cmd run serve:web
```

На компьютере откройте `http://127.0.0.1:4174`. Завершите анкету, дождитесь в профиле статуса «Доступно без интернета», затем отключите сеть и перезапустите приложение. Откройте «Питание → Рецепты», найдите «Банан молоко овсянка», совместите фильтры, отметьте ингредиент в режиме продуктов дома, добавьте блюдо в избранное и одну порцию в дневник. После повторного перезапуска проверьте избранное и запись на «Сегодня». Для проверок в Safari и установленной PWA используйте HTTPS-адрес разрешённой сборки и [инструкцию для iPhone](PWA.md#проверка-на-iphone). Для Expo Go на устройстве в той же сети используйте `npm.cmd run start -- --lan`.

### Браузерные проверки

Первый полный `npm run test:offline -- --workers=2` дал 134 успешных сценария, один штатный пропуск проверки CDP в WebKit и один таймаут при нажатии «Сохранить изменения» в сценарии профиля WebKit. На финальной сборке этот сценарий прошёл отдельно за 7,7 с. На той же сборке прошли все 14 тестов дневника и рецептов в Chromium и WebKit, включая холодный офлайн-запуск, сохранение избранного и истории, добавление блюда в дневник и обработку эквивалентных штрихкодов Open Food Facts.

Строгий статический UI-аудит прошёл без замечаний. Активный precache занимает около 2,54 МБ до сжатия. На локальном Chromium проверены две колонки при ширине 1280 px, геометрия страницы при 320 px и прокрутка всех 150 карточек. Шесть запросов из задания обновляли видимый счётчик за 35–99 мс в одной серии измерений. Применение фильтра заняло 49 мс. Chromium сообщил около 24 МБ используемой JS-кучи при первой порции результатов и 36 МБ после показа всех карточек. Эти числа относятся к локальной машине и включают интерфейс приложения.
