# Исправление фокуса полей ввода в PWA

26.11.2026. Исправление в рамках этапов 02/02.1. Этап 03 не начат; публикация и git push не выполнялись. Проверка на физическом iPhone не проводилась.

## Первопричина и воспроизведение

Общий `FormScreen` передавал `keyboardDismissMode="on-drag"` в `ScrollView`. В установленном `react-native-web` 0.21.4 обработчик `ScrollView._handleScroll` вызывает `dismissKeyboard()` при **любом** событии `scroll` в этом режиме, без проверки пользовательского жеста. Снятие фокуса происходит внутри зависимости, хотя явных `Keyboard.dismiss()` и `blur()` в коде форм нет.

В WebKit воспроизведён сценарий: открыть анкету, сфокусировать рост, ввести `1`, программно прокрутить настоящий прокручиваемый контейнер на 24 px без жеста. Поле становится неактивным, продолжение ввода теряется. До исправления регрессионный тест падал на `toBeFocused()`; после исправления ввод продолжается до `180,5`. Такая прокрутка совместима с доведением курсора до видимой области при изменении экранной клавиатуры/visual viewport Safari. Конкретный порядок событий на физическом iPhone не записывался.

Отдельная проверка обычного посимвольного ввода **без прокрутки** проходила и до исправления. Автосохранение само по себе не воспроизвело размонтирование поля. Поэтому первопричина подтверждённого сбоя — обработка прокрутки общего контейнера, а не предположение о пересоздании всей формы при каждом символе.

## Аудит всех полей

- В приложении один владелец `TextInput`: `src/components/form-controls.tsx`. Все поля анкеты и редактора используют `FormField` через общий `ProfileFields`.
- Проверены имя, дата рождения/расчёт возраста, рост, текущий и целевой вес, собственный темп, число тренировок, число приёмов пищи, режим питания, исключённые продукты, аллергии и ограничения. Самостоятельного редактируемого поля возраста нет: возраст вычисляется по дате рождения.
- Компоненты форм объявлены на уровне модулей. Внутренний `field()` — обычная функция, возвращающая JSX, вызывается как функция и не используется как новый тип компонента.
- Значения полей не используются в `key`. Для полей, создаваемых помощником, явно задан постоянный ключ имени поля. Ref регистрации стабилизирован через `useCallback`; обновление значения не требует отсоединения/присоединения ref.
- Редактор инициализирует черновик один раз через `useState`. Анкета меняет строки черновика синхронно и сохраняет их через существующую очередь. Завершение автосохранения меняет статус, не блокирует поле и не переинициализирует форму.
- Числа остаются исходными строками во время редактирования: `''`, `0,`, `180.` и другие промежуточные значения не отбрасываются и не форматируются. Дробная точка/запятая разбираются существующей валидацией при подтверждении. Проверки диапазонов не запускают blur или принудительное восстановление курсора.
- Обработчики `visualViewport`/`focusin`/`focusout` меняют высоту оболочки через CSS. Они не пересоздают компоненты и не снимают фокус. Код этих обработчиков сохранён.

## Исправление

- `FormScreen`: в веб-версии `keyboardDismissMode="none"`, чтобы автоматическая прокрутка Safari не закрывала клавиатуру. Нативный режим `on-drag` сохраняется: явный пользовательский жест может закрыть клавиатуру.
- `FormField`: единое сопоставление `inputMode` и нативного `keyboardType`; отключение автокоррекции, автокапитализации и проверки орфографии для чисел; стабильная регистрация ref. Автоматического перефокусирования и управления `selection` в приложении не добавлено.
- `ProfileFields`: дробные рост/веса/темп используют `decimal`/`decimal-pad`, целые счётчики — `numeric`/`number-pad`. На вебе числовые поля остаются текстовыми с подсказкой клавиатуры, поэтому поддерживают оба разделителя и API выделения. Для даты сохранена клавиатура с пунктуацией и отключена автокоррекция.
- Enter в однострочном поле остаётся явным действием закрытия. Многострочный ввод допускает перенос строки. Переключение поля, переход/сохранение и действия пользователя не блокируются.

Apple Minimal, тема, CSS, схема базы, репозитории, миграции, Service Worker, очередь записи и механизм обновлений не изменены.
