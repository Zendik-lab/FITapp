# Разработка и проверка

Для основной версии используйте [запуск, тестирование и публикацию PWA](PWA.md). Этот документ описывает дополнительную нативную проверку.

## Windows и Expo Go

Используйте PowerShell, Node.js 24 LTS и npm. Откройте проект, выполните `npm.cmd ci`, затем `npx.cmd expo login` и `npm.cmd run start -- --lan`. Установите на iPhone Expo Go 58.0.5 с поддержкой SDK 58, войдите в ту же учётную запись Expo и отсканируйте QR-код приложением «Камера». Если LAN недоступна, перезапустите Metro командой `npm.cmd run start -- --tunnel`. [Expo Go в App Store](https://apps.apple.com/kz/app/expo-go/id982107779) · [Запуск проекта на iPhone](https://docs.expo.dev/get-started/start-developing/)

## Проверка на физическом iPhone

- [ ] Открыть проект в Expo Go. При первом запуске после загрузки кода открывается «Сегодня», в терминале нет ошибок инициализации SQLite.
- [ ] Переключить все вкладки в обе стороны. Каждая вкладка отображает одноимённый русский заголовок.
- [ ] В профиле последовательно применить светлую, тёмную и системную тему. Закрыть и заново открыть Expo Go, убедиться, что выбранный режим сохранился. В системном режиме сменить тему через настройки iOS.
- [ ] В обеих темах прокрутить все пять экранов. Проверить читаемость, контраст, отсутствие наложений и выхода за горизонтальные границы. Проверить области выреза и индикатора «Домой» в портретной и альбомной ориентации. Повторить с увеличенным текстом.
- [ ] Выбрать другой день на экране «Сегодня», открыть «Питание» и проверить выбранную дату и пустой дневник. Переключить неделю и нажать на дату в заголовке календаря для возврата на сегодня.
- [ ] В «Прогрессе» переключить неделю, месяц, три месяца и год. Проверить даты, изменение веса и график в обеих темах.
- [ ] Открыть быстрые действия, добавление еды, поиск, сканирование, тренировку и параметры профиля. Проверить появление и закрытие диалога. При включённом системном тактильном отклике проверить отклик на смену вкладки.
- [ ] В терминале Expo нажать `Shift+M` и выбрать `Open expo-sqlite`. В инспекторе открыть `masstracker.db` и проверить обе таблицы, одну строку версии 1 в истории и базовые настройки.
- [ ] На тестовой базе через инспектор добавить пробную настройку, например `manual_check=retained`, с датой UTC. Закрыть Expo Go через переключатель приложений, открыть проект снова и проверить наличие пробной строки, исходного `applied_at` и единственной записи версии 1. После проверки удалить только пробную строку.
- [ ] Для проверки повторной попытки на тестовом экземпляре подставить однократное отклонение Promise в `initializeApp` через временное изменение исходника или отладчик, затем перезапустить JS. Проверить русское сообщение, технический журнал и успешный переход к вкладкам после «Повторить». Убрать временное изменение и повторно проверить штатный запуск.
- [ ] После первого открытия по LAN отключить доступ Wi-Fi-сети к интернету, сохранив соединение телефона и компьютера внутри LAN. Проверить переключение вкладок. Для проверки полностью без сети можно отключить связь на телефоне после загрузки кода и переключить вкладки без перезагрузки Expo Go.

SQL для тестовой записи в инспекторе.

```sql
INSERT INTO app_settings (key, value, updated_at)
VALUES ('manual_check', 'retained', strftime('%Y-%m-%dT%H:%M:%fZ', 'now'));

SELECT version, name, applied_at FROM schema_migrations ORDER BY version;
SELECT key, value, updated_at FROM app_settings ORDER BY key;

DELETE FROM app_settings WHERE key = 'manual_check';
```

Для проверки ошибки можно временно вставить объявление `let failOnce = true;` на уровне модуля `src/features/startup/initialize-app.ts`, а в начало тела `initializeApp` — блок ниже. Он не меняет файл базы.

```ts
if (failOnce) {
  failOnce = false;
  throw new Error('Тест повторной попытки');
}
```

Jest проверяет запуск и миграции с моками API Expo SQLite. Сценарии Expo Router покрывают вкладки и вызовы тактильного отклика, общую дату, диалог будущих функций, период графика и все три режима темы, включая повтор записи после сбоя. Физический iPhone нужен для проверки нативного интерфейса, отклика и сохранения темы после перезапуска приложения. [Инспектор Expo SQLite](https://docs.expo.dev/versions/v58.0.0/sdk/sqlite/#browse-an-on-device-database)

## Типичные ошибки

| Симптом                                      | Действие                                                                                                                                                                                |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PowerShell блокирует `npm.ps1` или `npx.ps1` | Использовать `npm.cmd` и `npx.cmd`. Если команд нет, проверить установку Node.js с npm и PATH.                                                                                          |
| Expo Go сообщает о несовместимой версии      | Проверить, что установлен Expo Go с поддержкой SDK 58. Для App Store она указана в истории версии 58.0.5.                                                                               |
| Expo Go сообщает о необходимости входа       | Выполнить `npx.cmd expo whoami` и проверить, что Expo Go использует ту же учётную запись.                                                                                               |
| QR-код открывается, но Metro недоступен      | Проверить, что компьютер и iPhone в одной сети, Expo Go имеет доступ к локальной сети iOS, а Windows Firewall допускает Node.js в частной сети. При необходимости использовать туннель. |
| Metro показывает устаревший код              | Остановить сервер и выполнить `npm.cmd run start -- --clear`.                                                                                                                           |
| SQLite не отвечает или возникла ошибка       | Нажать «Повторить» и проверить журнал Metro. Если нативная операция зависла, закрыть и заново открыть Expo Go. Файл базы сохраняется.                                                   |

Дополнительная информация по [запуску Expo Go](https://docs.expo.dev/get-started/start-developing/) и [входу в Expo](https://docs.expo.dev/troubleshooting/expo-go-sign-in-required/).

## Нативные ограничения и этапы

Expo Go использует встроенные нативные модули. HealthKit и нативные виджеты отложены до возможной отдельной iOS-сборки и настройки возможностей приложения. Windows позволяет запускать Metro и экспортировать JavaScript. Локальная сборка iOS с Xcode требует macOS.

Для закрытия этапа выполните проверки из README и обязательную ручную проверку. Зафиксируйте результат в CHANGELOG и обновите статус в ROADMAP. Начинайте следующий этап после явного разрешения пользователя.
