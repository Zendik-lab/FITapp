Личное приложение для iPhone, которое по мере развития будет объединять набор мышечной массы, питание, тренировки и восстановление. Основной язык — русский, единицы измерения — метрические, валюта — казахстанский тенге (KZT).

Основная версия — PWA для Safari на iPhone. После первого онлайн-запуска она открывается без сети и сохраняет данные локально. Первый запуск открывает анкету из восьми шагов; незавершённые ответы восстанавливаются. Профиль и цель можно редактировать по разделам. «Сегодня» показывает личные имя, вес, реальные калории и БЖУ дневника. Калькулятор доступен из профиля и питания; ручные цели сохраняются при пересчёте рекомендаций. Питание включает четыре приёма, историю по датам, поиск, свои продукты, избранное и недавние. Онлайн-поиск дополнительный; локальный дневник работает без сети. Вода, тренировки и прогресс сохраняют демонстрации предыдущих этапов. Нативная версия доступна через Expo Go.

## Технологии

- React Native, React, Expo SDK 58 и Expo Router.
- TypeScript в строгом режиме.
- IndexedDB в браузере и Expo SQLite на iOS через единый API локального хранения.
- Service Worker, Web App Manifest и статический экспорт без серверного backend.
- Lucide React Native и единый `AppIcon` для SVG-иконок, Expo Haptics на iOS и React Native SVG для графика и кольца.
- ESLint, Prettier и Jest с jest-expo.

## Окружение

- Windows 11 и PowerShell.
- Для воспроизводимых проверок — Node.js из `.node-version` (22.16.0) с npm. Другие совместимые версии указаны в `engines` файла `package.json`; результаты аудита Playwright и различия среды описаны в [отчёте UI/UX](docs/UI-UX-AUDIT.md).
- Для нативной проверки — физический iPhone с iOS 16.4 или новее, Expo Go для SDK 58 и учётная запись Expo.

Если PowerShell блокирует `npm.ps1` или `npx.ps1`, используйте `npm.cmd` и `npx.cmd`. Если команд нет, добавьте папку установки Node.js в PATH текущего сеанса.

Если Node.js установлен в переносимую папку MassTrackerTooling, подключите её к PATH.

```powershell
$env:Path = (Join-Path $env:LOCALAPPDATA 'MassTrackerTooling\node-v24.22.3-win-x64') + ';' + $env:Path
```

## Запуск PWA на Windows

```powershell
Set-Location -LiteralPath 'D:\FitApp'
npm.cmd ci
npx.cmd expo start --web
```

Для проверки production остановите Metro и используйте отдельный статический сервер с поддержкой прямых маршрутов.

```powershell
npm.cmd run build:web
npm.cmd run serve:web
```

Откройте `http://127.0.0.1:4174`. В Cloudflare Pages используйте **`npm run build:web`**, выходной каталог **`dist`**. Эта команда экспортирует Expo, затем генерирует Service Worker и `precache-manifest.json` из готовых файлов. Отдельного `expo export` для PWA теперь недостаточно. Скрипты используют Node.js без команд конкретной ОС; на Linux команды запускаются без суффикса `.cmd`.

Сборка также проверяет целостность готового `dist`. Повторная локальная проверка: `npm.cmd run verify:web`; проверка опубликованных байтов, MIME и маршрутов: `npm.cmd run verify:web -- https://fitapp-epj.pages.dev`. Публикуйте весь результат одной сборки. [Комплексная стабилизация 02.1: причины, результаты, настройки Cloudflare и проверка iPhone](docs/STABILIZATION-02.1.md).

В профиле именно установленного приложения дождитесь «Доступно без интернета»: статус появляется после проверки всех ресурсов кеша активным Service Worker. При сбое подготовка повторяется с возвращением сети или по кнопке. Инструкции по [проверке PWA, установке на iPhone и размещению на Cloudflare Pages](docs/PWA.md). [Диагностика и результаты HOTFIX Offline](docs/HOTFIX-01.1-OFFLINE.md).

## Запуск нативной версии

Установите на iPhone Expo Go 58.0.5 с поддержкой SDK 58. [Expo Go в App Store](https://apps.apple.com/kz/app/expo-go/id982107779)

```powershell
Set-Location -LiteralPath 'D:\FitApp'
npm.cmd ci
npx.cmd expo login
npm.cmd run start -- --lan
```

На iPhone войдите в ту же учётную запись в Expo Go, подключитесь к той же сети Wi-Fi и отсканируйте QR-код приложением «Камера». Если LAN недоступна, остановите Metro сочетанием `Ctrl+C`, запустите его через туннель и отсканируйте новый код.

```powershell
npm.cmd run start -- --tunnel
```

- Примеры калорий, веса, воды и тренировок находятся в памяти. Настройка темы хранится локально в каждом окружении.

## Этап 02.1 — Обновления PWA

Production-сборки получают уникальный ID. Приложение проверяет обновления при запуске, возврате из фона и восстановлении сети. Уведомление предлагает «Обновить» / «Позже»; в профиле доступны версия, ID сборки и ручная проверка. Применение блокируется при заполнении форм и ждёт сохранений. Офлайн-кеш и пользовательские данные сохраняются.

[Диагностика, механизм, изменённые файлы, проверки и инструкция для iPhone](docs/STAGE-02.1.md). Обязательна команда `npm run build:web`: она также создаёт `version.json` и заголовки обновлений. Публикация и ручная приёмка на устройстве ещё требуются; этап 03 не начат.
