# Правила работы AI-агентов

1. Перед любыми изменениями изучать AGENTS.md и ROADMAP.md.
2. Работать исключительно в рамках текущего этапа.
3. Не реализовывать функционал будущих этапов без разрешения пользователя.
4. Не удалять работающий функционал предыдущих этапов.
5. Не изменять архитектуру без обоснования и согласования существенных изменений.
6. Использовать строгую типизацию TypeScript.
7. Избегать any, дублирования кода и циклических зависимостей.
8. Разделять пользовательский интерфейс, бизнес-логику и работу с данными.
9. Использовать переиспользуемые компоненты.
10. Не размещать SQL-запросы непосредственно в UI-компонентах.
11. Использовать параметризованные SQL-запросы.
12. Все изменения схемы базы данных выполнять через миграции.
13. Не хранить секреты и токены в репозитории.
14. После каждого этапа выполнять проверки типов, линтер и тесты.
15. Не скрывать ошибки и не обходить проверки ради успешной сборки.
16. Не использовать фиктивные реализации вместо необходимого рабочего функционала.
17. Обновлять документацию после каждого этапа.
18. Не выполнять git push без разрешения пользователя.
19. Не переходить к следующему этапу автоматически.
20. Не считать успешную компиляцию доказательством полной работоспособности приложения.

## Платформы MassTracker

- Основная платформа — PWA для iPhone, установленная из Safari. Общий код остаётся на Expo, React Native, TypeScript и Expo Router. Нативная iOS-версия остаётся дополнительной.
- Этап 01.1 расположен между этапами 01 и 02. План этапов 02–13 сохранён. [Актуальная дорожная карта](ROADMAP.md) и [исходный план v1.0](docs/ROADMAP-v1.0.md).
- Приложение работает с локальным хранилищем через общий API. В браузере используется IndexedDB, в нативной версии — SQLite. Демонстрационные записи остаются в памяти.
- Веб-экспорт должен работать без сети и обязательного backend. Публикация и переход к следующему этапу требуют разрешения пользователя.
- Этап 14 для PWA охватывает доступные системные интеграции и улучшения мобильного опыта. Apple Health и виджеты отложены до отдельной нативной сборки. Резервное копирование и финальная публикация PWA относятся к этапу 15.
