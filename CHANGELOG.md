# Журнал изменений

## Этап 02.1 — PWA Update & Offline Reliability (26.11.2026)

- Уникальный ID каждого production-экспорта, согласованные метаданные HTML / worker / `version.json`, явные no-store заголовки проверки версии.
- Network First HTML с проверкой SHA-256 и согласованным офлайн-резервом. Ресурсы принадлежат своей сборке; очистка затрагивает только подтверждённых предшественников и сохраняет кеш следующей установки.
- Проверки при запуске, возобновлении и восстановлении сети; обнаружение waiting worker офлайн и активного worker при раннем деплое. Ошибки видны, повторная попытка доступна.
- Уведомление «Доступна новая версия», «Обновить» / «Позже»; версия, ID и проверка в профиле. Формы/диалоги и незавершённые записи защищены; reload ограничен целевой сборкой.
- Браузерные и модульные регрессии обновлений, нескольких окон, отказов, профиля/целей и офлайн-запуска. [Отчёт этапа](docs/STAGE-02.1.md). Production и физический iPhone требуют отдельной приёмки; этап 03 не начат.

## HOTFIX 01.1 — Complete PWA Offline Mode

- Добавлена обязательная сборка `npm run build:web`: экспорт Expo и генерация `sw.js` / `precache-manifest.json` из окончательного `dist`, включая SHA-256 HTML и все отложенные вкладки.
- Готовность офлайн-режима подтверждает активный SW проверкой полного кеша. Добавлены состояния подготовки, повтор по кнопке, online/visibility и восстановление отсутствующих ресурсов. После неудачной первой установки выполняется новая регистрация.
- Установка имеет ограничение ожидания ресурсов, неудачное обновление сохраняет предыдущую версию. Очистка касается только устаревших кешей приложения; схема и данные IndexedDB не менялись.
- Добавлены повторяемые Jest и Playwright-проверки офлайн-вкладок, настроек, полного перезапуска браузера и обновлений с сохранением данных. [Подробная диагностика и результаты](docs/HOTFIX-01.1-OFFLINE.md).
- Production не обновлялся. Этап 01.1 остаётся `IN_PROGRESS` до публикации и приёмки на физическом iPhone; этап 02 не начат.

## HOTFIX 01.1 — SVG-иконки PWA

- `expo-symbols` и шрифт Material Symbols заменены единым типизированным `AppIcon` на Lucide React Native и React Native SVG во всех пяти вкладках, карточках, кнопках, календаре и профиле. Размеры, темы и компоновка сохранены.
- Исправлен production-путь ресурсов зависимостей: Metro экспортирует их в `assets/vendor/`, поскольку Cloudflare Pages исключает вложенные `node_modules`. Это устраняет возврат HTML вместо ресурса и позволяет Service Worker завершить precache с проверкой контрольных сумм.
- Хеш сборки автоматически обновляет SW-кеш. Проверено сохранение IndexedDB и темы при обновлении, SVG офлайн и работа в Edge и Playwright WebKit. Физический iPhone недоступен; ручная приёмка Safari, установленной PWA и Expo Go остаётся обязательной.
- [Подробный отчёт и результаты проверок](docs/HOTFIX-01.1-ICONS.md). Этап 01.1 остаётся `IN_PROGRESS`; этап 02 не начат.

## Этап 01.1 — PWA и offline-first хранилище

- Подключены Expo Web, установка на домашний экран и автономный запуск пяти вкладок после первого онлайн-открытия.
- Тема и базовые настройки сохраняются в IndexedDB на вебе и в существующей SQLite на iOS через общий интерфейс. Хранилище поддерживает атомарную запись и чтение настроек для будущего резервного копирования.
- Веб-экспорт включает manifest, иконки и версионируемый Service Worker. Профиль показывает инструкцию Safari и доступность офлайн-режима. Приложение предлагает обновление после загрузки новой сборки.
- Актуальная дорожная карта фиксирует PWA как основную платформу. Исходный план v1.0 сохранён отдельно. Инструкции запуска, приёмки и публикации подготовлены.

## Этап 01 — Apple Minimal UI и навигация

- Пять русскоязычных экранов получили общую дизайн-систему, иконки SF Symbols, безопасные области и тактильный отклик при смене вкладки.

Статус этапа — `IN_PROGRESS` до приёмки на физическом iPhone.
