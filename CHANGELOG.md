# Журнал изменений

## Этап 01.1 — PWA и offline-first хранилище

- Подключены Expo Web, установка на домашний экран и автономный запуск пяти вкладок после первого онлайн-открытия.
- Тема и базовые настройки сохраняются в IndexedDB на вебе и в существующей SQLite на iOS через общий интерфейс. Хранилище поддерживает атомарную запись и чтение настроек для будущего резервного копирования.
- Веб-экспорт включает manifest, иконки и версионируемый Service Worker. Профиль показывает инструкцию Safari и доступность офлайн-режима. Приложение предлагает обновление после загрузки новой сборки.
- Актуальная дорожная карта фиксирует PWA как основную платформу. Исходный план v1.0 сохранён отдельно. Инструкции запуска, приёмки и публикации подготовлены.

## Этап 01 — Apple Minimal UI и навигация

- Пять русскоязычных экранов получили общую дизайн-систему, иконки SF Symbols, безопасные области и тактильный отклик при смене вкладки.
- «Сегодня» и «Питание» используют общий календарь. В «Прогрессе» работает график веса с четырьмя периодами.
- Профиль сохраняет выбор светлой, тёмной или системной темы в SQLite. Примеры показателей отделены от пользовательского хранилища.
- Действия будущих этапов открывают диалог. Обновлены проверка и инструкция запуска в Expo Go для SDK 58.

Статус этапа — `IN_PROGRESS` до приёмки на физическом iPhone.

## 0.1.0 — Этап 00

- Создано приложение MassTracker на Expo SDK 58 с React Native, TypeScript и Expo Router.
- Добавлены технические экраны «Сегодня», «Питание», «Тренировки», «Прогресс» и «Профиль», безопасные области и системные светлая и тёмная темы.
- Подключена локальная SQLite. Добавлены транзакционные миграции, история схемы, начальные настройки и базовый репозиторий.
- Реализованы загрузка настроек до показа вкладок, ограниченное ожидание, повторная попытка и обработка ошибок маршрутов.
- Настроены npm, Git, ESLint, Prettier и Jest. Добавлены тесты, документация и канонический план v1.0.

На Windows проверены переключение вкладок в среде Jest, запуск Metro по LAN, получение манифеста Expo Go и экспорт JavaScript для iOS. Отдельная проверка на SQLite под Windows подтвердила откат миграций и сохранение настройки после повторного открытия файла.

Статус этапа — `IN_PROGRESS` до проверки пользователем на физическом iPhone.
